# MiSans Global

本应用使用小米 MiSans Global 家族中的 MiSans VF，覆盖官方简体中文与拉丁字符范围。所有 56 个 WOFF2 切片来自小米官方 CDN，按原样保存，不修改字形或重新生成字体。CSS 保留官方 unicode-range，支持可变字重；构建后全部字体随 APK 内置，运行时不请求外部字体服务。

- 官方介绍与下载：https://hyperos.mi.com/font/zh/download/
- 来源地址、文件大小与 SHA-256：同目录 `source.json`。
- 原始许可协议：项目 `public/licenses/MiSans-License.pdf`，构建后同样随包保留。
- 应用内声明：设置面板底部“界面字体：MiSans Global（小米）”。

字体用于本应用界面，不作为独立字体产品分发或销售。请遵循小米 MiSans 字体知识产权许可协议。

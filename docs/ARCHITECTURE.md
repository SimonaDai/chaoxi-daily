# 开发说明

## 分层

| 目录                            | 职责                                                                   |
| ------------------------------- | ---------------------------------------------------------------------- |
| `src/domain`                    | 日期、农历、重复发生项、通知候选解析、保留期和导入结构校验；无设备 API |
| `src/platform`                  | IndexedDB / Capacitor、OCR、图片压缩、系统提醒、备份与公开政策同步     |
| `src/hooks/useAppModel.ts`      | 串行化写入，校验快照，协调设备服务和 UI 状态                           |
| `src/components`                | 日历、叠卡、编辑抽屉、截图录入和设置                                   |
| `src/data/holidays.json`        | 可审查的官方政策数据；不把普通周末当法定放假                           |
| `tests` / `e2e`                 | 规则边界与真实浏览器用户路径                                           |
| `android` / `.github/workflows` | Android 容器及检查、APK 构建入口                                       |

UI 不直接修改持久化数据；所有写入先经过 Zod 和串行写入队列。读取失败明确提示，不用空快照覆盖已有资料。当前是单设备、单编辑窗口设计，尚未实现多窗口合并或跨设备同步。

## 重复与单次修改

事项保存原始起始日和重复规则，不把每月发生项复制成多条记录。完成键与单次改期键均为 `eventId@原始发生日期`。改期显示在新日期，原日期不再显示，其他次不变。

月重复以原始日为锚点：1 月 31 → 2 月 28 → 3 月 31。2 月 29 的公历年重复在非闰年取 2 月末。农历闰月生日在有对应闰月时使用该闰月，其他年份使用同名普通月；没有对应日期时取农历月末。

调整整个系列的起始日、重复规则或终止日后，保留仍符合规则的单次修改；失效的单次修改重置，关联图片重新挂到新起始日而非删除。存在单次修改时保存前会明确确认。日期待定事项补日期也会迁移图片关联。

## 保存与图片清理

Android 图片在 `Directory.Data/photos/<安全 ID>`，文字快照在 Preferences；网页在 IndexedDB `chaoxi-local-v1`。附件 ID 只允许字母、数字、连字符和下划线，导入拒绝路径穿越。图片保存成功后才提交引用；快照提交失败回滚新附件。

清理条件为 `now >= 保存时间加一个自然月` 且发生项已结束，两者同时成立。自然月收敛月末、保留北京时间时分秒，全天事项保留到次日 00:00。未来事项、待定日期及无法解析的关联采取保守保留策略；单次改期按改后日期判断。删除仅针对应用副本。

清理先持久化元数据变更和 `pendingPhotoDeletes` 队列，再删文件，最后确认队列。文件删除失败保留队列，下一次前台继续；保存计划失败不删文件。进程被系统杀掉时不保证立刻回收空间，但可在后续打开时重试。

如果在“新文件落盘、快照尚未提交”之间被强制断电，可能留下未引用的文件。当前没有扫描磁盘自动删除孤立文件的功能，避免误删；这是可继续完善的空间回收边界。

## 导出与恢复

备份包含 `app`、`version`、`exportedAt`、经过校验的 snapshot 以及图片 base64。导入检查版本、日期、分类引用、ID 唯一性、图片映射完整性、MIME 与字节长度；不识别其他软件的备份格式。

恢复先给导入附件分配新 ID 并写入，全部完成后切换快照，旧附件进入可重试删除队列。写入失败保留原快照并回滚已写入的新附件。备份文件本身含个人资料，不上传到代码仓库。

## OCR 与隐私

Tesseract.js 7、LSTM WASM 和中英文模型随构建复制。模型在构建时预解压，消除 WebView/服务器对 `.gz` 内容编码的差异；APK 会再次压缩资源。OCR 无云端密钥、无在线识别服务。识别可取消，旧任务结果不会写入新任务。

候选解析只接受完整明确日期，不推测省略的年份；多个日期留给用户确认。时间只在日期明确且数量简单时提供建议。保留原文，默认不提醒。识别模型无法读取时退回仅附图/手动填写。

网络能力只有用户填写的公开政策 URL，未设置时不主动请求网络。没有账号、遥测、广告、云数据库。Android 禁止系统云备份与自动设备迁移；备份分享由用户触发。

## 假期更新协议

根对象包含 `schemaVersion: 1` 和 `policies`。每年政策包含 `year`、递增正整数 `revision`、`publishedAt`、官方 HTTPS `source` 及 `ranges`，区间包含 `start`、`end`、`kind: off|work` 和名称。

校验限制政府来源域名、同年有效日期、区间上限、不重复/不冲突；只合并较新 revision，保留其他年份。字段校验不证明政策内容真实，仍需要维护者审查官方原文。缓存失败/联网失败不丢掉已有政策；没有数据的年份显示待更新。当前内置 2026 年安排。

## 提醒边界

启动只检查已有通知权限。用户保存启用提醒的事项时才请求通知权限；调度明确设置 `isExactNotification: false`，Manifest 移除插件自带的精确闹钟权限，避免额外设置弹窗。滚动安排未来 60 天最多 200 条，已完成、已取消、已过期提醒跳过。长期不打开应用不会永久补排。

## 验证和已知限制

- 测试覆盖北京时间边界、月末/闰年/农历、单次改期、保留期、删除失败重试、备份导入、政策修订、提醒默认行为。
- Playwright 使用真实浏览器验证存储、重载、叠卡拖动、分类颜色、截图导出、随包 OCR，并断言识别不请求第三方服务。
- jsdom 的 Blob 无法被 Node structuredClone 完整克隆，单元测试对备份图片使用内存适配器，真实 Blob 持久化由浏览器测试覆盖。
- 当前开发机无 JDK/Android SDK，APK 编译和系统通知、分享、厂商 WebView/节电行为需 GitHub 与真机验证。不能用网页测试通过替代 APK 验收。
- 2026-10-27 依赖审计：生产依赖 0 项漏洞；完整开发树中 Capacitor CLI 的 iOS `xcode → uuid` 链有 3 项 moderate 报告。Android 运行包不包含该开发链，未通过强制大版本降级消除审计提示。后续留意上游修复；不宣称完整开发树零告警。
- Tesseract 上游在部分初始化失败路径中可能不返回 worker 对象；应用提供超时、取消和错误提示，已成功返回的引擎会释放，极端初始化失败可关闭后重新打开应用。
- 暂未实现应用加密锁、自动跨设备同步、全年永久后台提醒或商店发布。这些需独立任务设计与验收。
